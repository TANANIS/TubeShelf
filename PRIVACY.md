# TubeShelf Privacy Policy / 隱私權政策

Last updated / 最後更新：2026-09-06

## 繁體中文

TubeShelf 的單一用途是協助使用者在 YouTube 上整理、篩選與管理自己的訂閱頻道。

TubeShelf 會在使用者操作 YouTube 時處理公開可見的頁面內容，包括訂閱頻道名稱、頻道網址與 ID、公開頭像、公開頻道簡介、近期影片標題、YouTube 公開主題與影片類別，以及訂閱／取消訂閱狀態。TubeShelf 也會處理使用者建立的群組、手動分類、偏好設定與介面語言。

上述資料預設只儲存在使用者瀏覽器的 `chrome.storage.local`。TubeShelf 不經營伺服器，不傳送遙測或分析資料，不出售資料，不用於廣告，也不允許開發者或其他人員閱讀使用者的訂閱與群組資料。

若使用者自行選擇填入 YouTube Data API Key，TubeShelf 會透過 HTTPS 直接把該 Key、公開的 YouTube channel ID 與 video ID 傳送至 Google YouTube Data API，以取得公開頻道主題、標籤與影片類別。API Key 只儲存在本機，且不會包含在 TubeShelf JSON 備份中。除這項由使用者主動啟用的 Google API 功能外，TubeShelf 不會把資料傳送給第三方。

使用者可在偏好設定匯出或匯入自己的 JSON 備份。匯出只由使用者主動觸發，檔案不會上傳給開發者。使用者可使用「清除本機資料」刪除 TubeShelf 儲存的頻道、群組與設定，也可解除安裝擴充套件移除其本機資料。

TubeShelf 對從 Google API 收到之資訊的使用，將遵守 Chrome Web Store User Data Policy，包括 Limited Use requirements。

如對本政策有疑問，請透過 TubeShelf 的 Chrome Web Store 支援頁面聯絡開發者。

## English

TubeShelf has one purpose: helping users organize, filter, and manage their YouTube subscriptions.

While the user interacts with YouTube, TubeShelf processes publicly visible page content including subscribed channel names, channel URLs and IDs, public avatars, public channel descriptions, recent video titles, public YouTube topics and video categories, and subscribe/unsubscribe state. TubeShelf also processes groups, manual classifications, preferences, and interface language created or selected by the user.

This data is stored locally in the user's browser using `chrome.storage.local` by default. TubeShelf operates no server, sends no telemetry or analytics, does not sell data, does not use data for advertising, and does not allow the developer or other people to read a user's subscription or group data.

If the user chooses to provide a YouTube Data API key, TubeShelf sends that key together with public YouTube channel IDs and video IDs directly to the Google YouTube Data API over HTTPS to retrieve public channel topics, tags, and video categories. The API key remains on the device and is excluded from TubeShelf JSON backups. Except for this user-enabled Google API feature, TubeShelf does not transfer data to third parties.

Users may manually export or import their own JSON backup in Preferences. Exports are initiated only by the user and are not uploaded to the developer. Users can delete TubeShelf's stored channels, groups, and settings with Clear local data, or remove local extension data by uninstalling the extension.

TubeShelf's use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

For questions about this policy, contact the developer through TubeShelf's Chrome Web Store support page.
